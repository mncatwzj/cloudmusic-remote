### 功能
- 默认鼠标侧上键 XButton2 切下一首，可切换 XButton1。
- 手机局域网控制播放 / 暂停、上一首、下一首、音量增减。
- 配对码、曲目标题显示与托盘运行。

### 安装
下载 `CloudMusicRemote-v0.1.0-win-x64.zip`，解压后运行 `CloudMusicRemote.exe`。支持 Windows 10/11 x64，需要可用的网易云默认全局快捷键。无需 Node.js 或 Python。

手机连同一局域网，打开电脑面板上的地址，输入配对码。连接受阻时使用面板的“允许手机连接…”按钮，并自行完成管理员确认。

`SHA256SUMS.txt` 提供压缩包校验值。EXE 尚未进行代码签名。

### 已知限制
- v0.1.0 使用固定的网易云全局快捷键，不支持自动识别自定义快捷键。
- 音量逐档调节，没有绝对音量滑块；播放状态不作猜测。
- 使用明文 HTTP，仅适用于可信局域网，不要开放到公网。
- 自动化接口测试通过，网页上一首 / 下一首已有本机实测；不同鼠标、真实手机与网易云版本仍需进一步验证。
