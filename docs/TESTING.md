# 验证范围

## v1.0.0

37 项自动化断言通过，新增默认及自定义快捷键、修饰键、重复冲突、无修饰键拒绝、上/下侧键和禁用双侧键逻辑验证。UI 原型不作为实际功能验证依据。

正式程序实测：原生窗口启动、真实网易云曲目标题读取、快捷键录入 Ctrl+Shift+N 并写入本机配置、恢复默认快捷键均通过。正式手机页面已完成真实配对，下一首操作观察到曲目变化，并执行上一首返回操作。尚未覆盖所有真实鼠标、手机网络及客户端版本。

## 自动化

`scripts/Test.ps1` 启动独立的本地测试服务器，使用测试实例自己的随机配对码验证：

- 首页可访问，控制页资源完整；
- 无凭据和错误凭据不能查询状态；
- 正确配对能访问状态；
- 错误配对限流；
- 非法 JSON、缺失操作、未知操作被拒绝；
- 不正确的 Host 和跨站 Origin 被拒绝；
- 正常状态接口在配对限流后仍可使用；
- IP 地址过滤边界。

这些测试不会安装鼠标钩子、触发实际播放操作、修改音量或更改防火墙。它们不等于真实设备验收。

## 首版开发时的手工检查

- Windows x64 编译通过，控制面板正常显示。
- 核对网易云全局快捷键配置，实际验证快捷键播放 / 暂停并恢复播放。
- 从局域网地址打开浏览器页面，配对成功。
- 网页下一首与上一首均观察到网易云曲目标题发生相应变化。
- 检查可选防火墙规则限定程序路径、单个端口和 LocalSubnet。

尚未完整验证：真实手机经 Wi-Fi 连接、不同鼠标的物理侧键、音量增减在各网易云版本中的行为、锁屏 / 休眠恢复、所有 DPI 和辅助功能组合。

## 发布前建议人工验收

1. 准备测试播放列表，记录当前歌曲和音量。
2. 在另一个应用处于前台时，按实际鼠标 XButton2，确认只切一首；切换 XButton1 再验证。
3. 停用侧键映射，检查侧键原功能恢复。
4. 手机浏览器配对，依次测试上一首、下一首、播放 / 暂停、音量增减，并恢复音量。
5. 退出网易云，确认遥控页说明需要先打开客户端。
6. 关闭工具窗口，确认托盘控制仍可用；再次双击 EXE，确认唤起同一面板。
7. 退出工具并重启，确认旧凭据失效且能重新配对。
8. 断开网络、错误配对、切换 IP，检查错误提示和恢复路径。

不要使用 CI 自动触发用户正在播放的歌曲。
