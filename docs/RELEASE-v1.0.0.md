# 随手控 v1.0.0

首个正式版本。MIT 开源，源码、Windows x64 程序和 SHA-256 校验文件一并提供。

## 从 0.1.0 更新了什么

### 原生桌面界面
- 将早期 WinForms 界面替换为原生 WPF 桌面窗口，不是桌面网页。
- 使用 ChatGPT 风格的深色侧栏、圆角卡片与设置布局。
- 支持窗口缩放；较窄时收起侧栏，正文随窗口调整并可滚动。
- 新增侧键滑动选中动画、按钮悬停和按压反馈、状态文字淡入。
- 在桌面上查看网易云窗口标题、控制播放及管理手机配对。

### 侧键与快捷键
- 侧键改为“上侧键 / 下侧键 / 禁用”三选一。
- 禁用后两侧键均不触发本工具切歌；鼠标在其他程序中的原有用途保留。
- 在软件内录入播放 / 暂停、上一首、下一首和音量增减快捷键，匹配用户已设定的网易云全局快捷键，不要求去改网易云。
- 支持快捷键冲突校验、取消录入、恢复默认和本机持久化保存。
- 录入时临时拦截主按键，避免被录入的组合键同时触发其他应用；失去焦点或结束录入即卸载录入钩子。
- 兼容迁移旧版侧键偏好。

### 手机遥控
- 仅保留一版液态玻璃风格手机遥控页面，加入渐变流动背景、悬浮装饰和按钮按压动效。
- 连接真实配对、曲目标题、播放控制及音量增减接口。
- 移除 UI 原型的演示配对码、示例曲目、假播放进度、假音量滑块和测试入口。
- 不虚构真实播放状态或绝对音量；播放按钮明确为“播放 / 暂停”，音量按档调节。

## 安装与升级
下载 `CloudMusicRemote-v1.0.0-win-x64.zip` 并完整解压，先退出旧版，再运行 `CloudMusicRemote.exe`。

手机连接同一网络，在浏览器打开桌面面板中的地址并输入配对码。移动程序目录后，如手机无法连接，可重新点击“允许手机连接…”并完成 Windows 管理员确认。

配置保存在 `%LOCALAPPDATA%\CloudMusicRemote\preferences.json`。旧版 `settings.txt` 会在首次没有新配置时用于迁移侧键选项。

## 验证与边界
自动化检查覆盖局域网接口、配对、权限、输入校验、自定义快捷键及侧键禁用逻辑。仍需在各自的鼠标、手机网络和网易云版本上确认兼容性。

程序尚未进行代码签名；仅适用于可信局域网的 HTTP 连接，不要对公网开放。全局快捷键需要未被其他应用占用，且网易云与本工具的运行权限一致。
